# TreeMaker

Небольшое приложение на С++, которое должно помочь мне создавать генеалогические деревья (и не только). Этот проект необходим мне для создания другого. Мне нужно удобное приложение которое прийдёт на замену `draw.io`.

## Как запустить

> Я использую среду разработки `Visual Studio Code` с использованием языка программирования `C++`, так что инструкция будет нацеленна именно на такие настройки.

**Скачайте компилятор С++**

1. Я использую установщик [**MSYS2**](https://www.msys2.org/)
2. Откройте терминал `MSYS2 UCRT64` и вбейте следующие строки:
```bash
pacman -S mingw-w64-ucrt-x86_64-toolchain \
          mingw-w64-ucrt-x86_64-cmake \
          mingw-w64-ucrt-x86_64-ninja \
          mingw-w64-ucrt-x86_64-gdb \
          mingw-w64-ucrt-x86_64-glfw \
          mingw-w64-ucrt-x86_64-glew \
          mingw-w64-ucrt-x86_64-glm
```

**Добавление в PATH**

В приложении `Изменение системных переменных` => `Переменные среды` => `Системные переменные` => `Path` нажмите на кнопку `Создать` и добавте новый путь:
```text
C:\msys64\ucrt64\bin
```

Для проверки вбейте в обычный `cmd` или `powershell`:
```bash
g++ --version
cmake --version
gdb --version
```

**Запуск**

1. Убедитесь что в `VSCode` у вас скачаны все необходимы расширения (для С\С++ и CMake)
2. `Ctrl+Shift+P` => `CMake: Select a Kit`
3. После этого запускате проект через нижние кнопки.
